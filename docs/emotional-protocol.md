# 口播稿情绪数值控制协议

## 一、情绪标尺定义

| 数值 | 情绪 | 留学生求职赛道含义 |
|---|---|---|
| -1.0 | 极度焦虑/恐惧 | 找不到工作、被淘汰、错过窗口期、学费白花了 |
| -0.5 | 轻微担忧/困惑 | 信息差、不知道政策、在无效竞争、蒙在鼓里 |
| 0.0 | 中性/陈述 | 事实描述、政策原文、活动通知、数据呈现 |
| +0.5 | 希望/轻松 | 有绿色通道、门槛降低、留学生专属、有解决方案 |
| +1.0 | 兴奋/确定/安全感 | 稳进编制、高额补贴、免笔试上岸、金饭碗 |

## 二、标准情绪曲线

| 稿件类型 | 曲线形状 | 数值走势 | 心理学原理 |
|---|---|---|---|
| **避坑警示类** | V型反转 | Hook(-0.8)→Trust(-0.3)→Solution(+0.7)→CTA(+0.5) | 先制造焦虑，再炫耀式救赎 |
| **红利揭秘类** | 阶梯上升 | Hook(-0.2)→Trust(+0.4)→Solution(+0.9)→CTA(+0.9) | 从好奇到兴奋，最后居高临下收尾 |
| **招聘会资讯类** | 脉冲式 | Hook(+0.4)→Info(+0.6)→Filter(+0.3)→CTA(+0.7) | 快速抓注意，秀专属门槛，促行动 |

## 三、分阶段执行指令

### Phase 1: Hook (0-3秒) | 目标情绪: -0.7 ~ -0.5 或 +0.4

**任务**: 打破认知或制造紧迫，一句话建立"我知道你不知道"的信息差姿态。

**强制词汇**:
- V型/阶梯: "醒醒吧"、"大错特错"、"太可惜了"、"白交了"、"蒙在鼓里"、"真正懂行的家长早就……"
- 招聘会: "注意了"、"重磅来袭"、"快来捡漏"、"刚刚官宣"、"普通人根本不知道的……"

**句式**: 强反问、否定句、时效提醒句、圈层施压句
**禁止**: 温和的建议、平铺直叙

### Phase 2: Trust (3-10秒) | 目标情绪: -0.2 ~ 0.0

**任务**: 建立可信度，展开说明。

**强制词汇**: "数据显示"、"上面刚刚定音"、"教育部举办"、"省教育厅牵头"、"HR内部透露"
**句式**: 短句陈述、引用权威
**注意**: 保持冷静专业，为后面高潮做铺垫。语气要有"我在告诉你一个你查不到的东西"的感觉。

### Phase 3: Solution (10-35秒) | 目标情绪: +0.7 ~ +0.9

**任务**: 抛出红利/方案，展示确定性。必须出现与国内学生的对比。

**强制词汇**: "稳进"、"免笔试"、"降维打击"、"金饭碗"、"真金白银"、"专属通道"、"上岸"、"跳过网申"、"QS前XX优先"、"甩开国内统招"、"不用跟国内生挤"
**句式**: 排比句、数字锚定、对比句（海归 vs 国内生）
**注意**: 情绪饱满，语速加快，强调"容易"和"高回报"。必须至少 2 处区分国内学生，每处不超过一句半，嵌在信息里不成段。

### Phase 4: CTA (35-50秒) | 目标情绪: +0.5 ~ +0.7

**任务**: 居高临下地给资源，降低行动门槛但不降姿态。

**强制词汇**: "打包好了"、"逐一发"、"评论区敲"、"悄悄我"、"别客气"、"悠悠老师发你"
**句式**: 祈使句、邀请句
**注意**: 保持精英感收官，像在分享一个"本来不想公开"的资源。不是朋友聊天，是专家施舍。

## 四、如何与 structure-templates.md 配合使用

1. 先选骨架（A1 / A2 / B）
2. 再定情绪曲线
3. 每个段位同时参考骨架的"做什么"和本协议的"强制词汇+句式"

**示例**：写一篇招聘会稿
- 骨架 B：Hook → 信息 → 参与方式 → 紧迫 → CTA
- 情绪曲线：脉冲式
- Hook 段位 = 骨架 Hook + 情绪 Phase 1（招聘会词汇）
- 信息段位 = 骨架信息 + 情绪 Phase 2（权威陈述）
- 参与方式+紧迫 = 骨架参与+紧迫 + 情绪 Phase 3（红利词汇）
- CTA = 骨架 CTA + 情绪 Phase 4
